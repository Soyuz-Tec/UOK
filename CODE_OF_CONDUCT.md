# UOK Code of Conduct

**Status:** Active community standard
**Target:** UOK contributors and maintainers
**Purpose:** Protect respectful, technically rigorous collaboration.
**Scope:** Repository discussions, issues, pull requests, reviews, and project events.

## Expected Conduct

Participants must:

- discuss ideas and evidence without personal attacks;
- welcome questions and explain project-specific expectations;
- respect privacy, security embargoes, and confidential reports;
- give actionable review feedback tied to behavior, risk, or maintainability;
- disclose relevant conflicts of interest;
- stop disruptive behavior when asked by a maintainer.

Harassment, discrimination, threats, doxxing, sexualized conduct, deliberate
misinformation, and retaliation are not accepted.

## Enforcement

Maintainers may edit or remove content, limit participation, close discussions,
or block accounts when necessary to protect the project and its participants.
Enforcement should be proportional, documented privately when appropriate, and
free from retaliation.

Use GitHub's moderation and report-abuse controls for conduct incidents. Do not
use public issues for private personal information or security vulnerabilities.
Security reports follow `SECURITY.md`.

## Validation

Repository community-profile checks should discover this file. Updates require
the same review and documentation checks as other active governance records.
