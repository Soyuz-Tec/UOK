# UOK Support

**Status:** Active support routing guide
**Target:** UOK 3.1.0 alpha
**Purpose:** Route questions, defects, feature requests, and security reports correctly.
**Scope:** Public repository support.

| Need | Route |
|---|---|
| Reproducible defect | GitHub bug report template |
| Bounded product or engineering improvement | GitHub feature request template |
| Usage, architecture, or contributor question | [GitHub question form](https://github.com/Soyuz-Tec/UOK/issues/new?template=question.yml) |
| Vulnerability or sensitive security concern | Private report described in `SECURITY.md` |
| Conduct concern | GitHub moderation/report-abuse controls |

Repository Discussions and blank issues are disabled. Use the linked question
form for public questions so the request has enough context to be actionable.

UOK is an alpha project and has no guaranteed response or production support
SLA. Include the exact commit or tag, operating system, runtime versions,
reproduction steps, expected result, actual result, and sanitized logs.

Never post passwords, tokens, personal data, private database dumps, or other
secrets.
